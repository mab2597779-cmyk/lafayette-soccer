# Lafayette Varsity Soccer — Showcase Website

A responsive, static fan-made showcase for Lafayette International High School soccer.

## Preview locally
Open `index.html` in a browser. For best results, use a local static server (e.g. VS Code Live Server).

## Publish free with GitHub Pages
1. Create a GitHub account and a new **public** repository.
2. Upload the contents of this folder (index.html, style.css, script.js, assets/).
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for GitHub Pages to publish and use the URL it gives you.

## Important notes
- This is an unofficial fan-made concept, not an official school website. Get school approval before presenting it as official.
- The kit imagery is used as image-based mockups. Dragging rotates the presentation card for an interactive showroom effect, but this is **not a true 3D jersey mesh**. For real 3D rotation showing accurate sides/back, a textured `.glb` jersey model is needed.
- The number selector is a UI preview; it does not redraw the actual jersey artwork or customize a real garment.
- Historical timeline includes sourced context: the original Lafayette building opened in 1903; Lafayette International High School was introduced in 2016. The exact founding year of the current varsity soccer program has not been verified.
- Match archive links lead to external public listings and Hudl highlights. Confirm current results directly before relying on them.
- The first kit image contains supplier watermarks; obtain clean, authorized art before public use.
